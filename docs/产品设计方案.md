# EXE开发者中心 - 概要设计方案

## 一、方案概述

### 1.1 设计目标
构建一个企业开发者平台，支持开发者创建产品、配置能力、管理终端版本，实现EPASS开发功能的商业化封装。

### 1.2 技术选型

| 层级 | 技术方案 |
|-----|---------|
| 前端 | Vue3 + TypeScript + Element Plus |
| 后端 | Node.js + TypeScript + Express |
| 数据库 | **SQLite**（单文件数据库，无需服务器） |
| ORM | TypeORM |
| 文件存储 | 本地文件系统 |
| 构建工具 | Vite |

### 1.3 技术选型理由
- **SQLite**：无需安装服务器，单文件存储，适合本地开发和演示
- **Node.js**：轻量高效，与前端技术栈统一
- **TypeScript**：类型安全，提升开发效率
- **Vue3**：组件化开发，响应式系统

## 四、接口设计概要

### 4.1 模块划分

| 模块 | 基础路径 | 说明 |
|-----|---------|------|
| 认证模块 | `/api/auth` | 注册、登录、验证码 |
| 用户模块 | `/api/user` | 用户信息、企业认证 |
| 团队模块 | `/api/team` | 团队管理、成员管理 |
| 能力模块 | `/api/capability` | 能力CRUD、配置包管理 |
| 产品模块 | `/api/product` | 产品CRUD、场景方案、终端配置 |

## 六、安全设计

| 安全项 | 方案 |
|-------|------|
| 认证 | JWT Token，Access Token + Refresh Token 双令牌机制 |
| 密码 | bcryptjs 加密存储，成本因子 10 |
| 接口鉴权 | JWT Middleware 验证，白名单接口除外 |
| 数据隔离 | 每个查询添加 teamId 过滤条件 |
| 敏感操作 | 记录操作日志（用户ID、操作类型、时间、IP） |
| 上传安全 | 文件类型白名单（jpg/png/gif）、大小限制（2MB）、文件名重命名 |
| SQL注入 | 使用 TypeORM 参数化查询 |
| XSS防护 | 前端输入过滤，后端输出转义 |

## 八、启动方式
