# EXE开发者中心 - 数据库设计文档

## 一、数据库概述

### 1.1 数据库选型
- **数据库**：SQLite 3
- **ORM**：TypeORM
- **存储方式**：单文件存储 (`developer.db`)
- **特点**：无需服务器，零配置，适合本地开发和演示

### 1.2 实体关系概览


## 二、核心实体定义

### 2.1 用户与认证模块

#### User (用户表)
存储用户基础信息

| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 主键ID |
| username | TEXT | NOT NULL, UNIQUE | 用户名 |
| password | TEXT | - | 密码（bcrypt加密） |
| phone | TEXT | UNIQUE | 手机号 |
| email | TEXT | UNIQUE | 邮箱 |
| real_name | TEXT | - | 真实姓名 |
| status | INTEGER | DEFAULT 1 | 状态：0-禁用 1-启用 |
| created_at | TEXT | DEFAULT datetime('now') | 创建时间 |
| updated_at | TEXT | DEFAULT datetime('now') | 更新时间 |

**索引**：
- `uk_username`：username 唯一索引
- `uk_phone`：phone 唯一索引
- `uk_email`：email 唯一索引

---

#### EnterpriseAuth (企业认证表)
存储企业认证信息

| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 主键ID |
| user_id | INTEGER | NOT NULL | 用户ID |
| enterprise_name | TEXT | NOT NULL | 企业名称 |
| credit_code | TEXT | - | 统一社会信用代码 |
| license_url | TEXT | - | 营业执照图片URL |
| legal_person | TEXT | - | 法人姓名 |
| status | INTEGER | DEFAULT 0 | 认证状态：0-未认证 1-审核中 2-已认证 3-认证失败 |
| created_at | TEXT | DEFAULT datetime('now') | 创建时间 |

**索引**：
- `idx_user_id`：user_id 普通索引

---

### 2.2 团队管理模块

#### Team (团队表)
存储团队信息

| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 主键ID |
| name | TEXT | NOT NULL | 团队名称 |
| owner_id | INTEGER | NOT NULL | 创建人/负责人ID |
| description | TEXT | - | 团队描述 |
| created_at | TEXT | DEFAULT datetime('now') | 创建时间 |

---

#### TeamMember (团队成员表)
存储团队成员关系

| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 主键ID |
| team_id | INTEGER | NOT NULL | 团队ID |
| user_id | INTEGER | NOT NULL | 用户ID |
| role | INTEGER | DEFAULT 2 | 角色：1-管理员 2-开发者 3-运营 |
| status | INTEGER | DEFAULT 1 | 状态：0-待接受 1-已加入 2-已退出 |
| joined_at | TEXT | - | 加入时间 |

**索引**：
- `uk_team_user`：team_id + user_id 联合唯一索引

---

### 2.3 能力管理模块

#### Capability (能力表)
存储能力信息

| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 主键ID |
| code | TEXT | NOT NULL, UNIQUE | 能力编码 |
| name | TEXT | NOT NULL | 能力名称 |
| description | TEXT | - | 能力描述 |
| icon_url | TEXT | - | 能力图标URL |
| team_id | INTEGER | - | 所属团队ID（NULL表示平台预设） |
| epass_func_id | TEXT | - | 关联EPASS功能ID |
| status | INTEGER | DEFAULT 0 | 状态：0-草稿 1-已发布 2-已下架 |
| created_at | TEXT | DEFAULT datetime('now') | 创建时间 |

**索引**：
- `uk_code`：code 唯一索引
- `idx_team_id`：team_id 普通索引

---

#### ConfigPackage (配置包表)
存储配置包信息

| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 主键ID |
| capability_id | INTEGER | NOT NULL | 能力ID |
| name | TEXT | NOT NULL | 配置包名称 |
| description | TEXT | - | 配置包描述 |
| created_at | TEXT | DEFAULT datetime('now') | 创建时间 |

**索引**：
- `idx_capability_id`：capability_id 普通索引

---

#### ConfigPackageItem (配置包参数表)
存储配置包中的参数

| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 主键ID |
| package_id | INTEGER | NOT NULL | 配置包ID |
| param_key | TEXT | NOT NULL | 参数键 |
| param_name | TEXT | - | 参数名称 |
| param_type | INTEGER | NOT NULL | 参数类型：1-字符 2-布尔 3-日期 |
| param_value | TEXT | - | 参数值 |
| sort_order | INTEGER | DEFAULT 0 | 排序 |

**索引**：
- `idx_package_id`：package_id 普通索引

---

### 2.4 产品管理模块

#### Product (产品表)
存储产品基础信息

| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 主键ID |
| code | TEXT | NOT NULL, UNIQUE | 产品编码 |
| name | TEXT | NOT NULL | 产品名称 |
| description | TEXT | - | 产品描述 |
| icon_url | TEXT | - | 产品图标URL |
| category | TEXT | - | 产品分类 |
| team_id | INTEGER | NOT NULL | 所属团队ID |
| status | INTEGER | DEFAULT 0 | 状态：0-草稿 1-已发布 2-已下架 |
| created_at | TEXT | DEFAULT datetime('now') | 创建时间 |
| updated_at | TEXT | DEFAULT datetime('now') | 更新时间 |

**索引**：
- `uk_code`：code 唯一索引
- `idx_team_id`：team_id 普通索引

---

#### ProductCapability (产品能力关联表)
存储产品与能力的关联关系

| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 主键ID |
| product_id | INTEGER | NOT NULL | 产品ID |
| capability_id | INTEGER | NOT NULL | 能力ID |
| config_package_id | INTEGER | - | 使用的配置包ID |
| status | INTEGER | DEFAULT 1 | 状态：0-禁用 1-启用 |

**索引**：
- `uk_prod_cap`：product_id + capability_id 联合唯一索引
- `idx_product_id`：product_id 普通索引

---

#### AdminMenu (管理后台菜单表)
存储产品管理后台菜单配置

| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 主键ID |
| product_id | INTEGER | NOT NULL | 产品ID |
| parent_id | INTEGER | DEFAULT 0 | 父菜单ID，0为根 |
| name | TEXT | NOT NULL | 菜单名称 |
| icon | TEXT | - | 菜单图标 |
| path | TEXT | - | 菜单路径 |
| sort_order | INTEGER | DEFAULT 0 | 排序 |
| visible_roles | TEXT | - | 可见角色（逗号分隔） |

**索引**：
- `idx_product_id`：product_id 普通索引
- `idx_parent_id`：parent_id 普通索引

---

#### Scenario (场景方案表)
存储产品场景方案配置

| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 主键ID |
| product_id | INTEGER | NOT NULL | 产品ID |
| code | TEXT | NOT NULL | 方案编码 |
| name | TEXT | NOT NULL | 方案名称 |
| login_identity_config | TEXT | - | 登录身份条件配置（JSON） |
| h5_portal_config | TEXT | - | H5门户配置（JSON） |
| pc_portal_config | TEXT | - | PC门户配置（JSON） |
| created_at | TEXT | DEFAULT datetime('now') | 创建时间 |

**索引**：
- `idx_product_id`：product_id 普通索引

---

#### ScenarioCapability (场景能力配置表)
存储场景方案中启用的能力。场景能力必须来自当前场景所属产品已关联的能力，产品能力仍被场景引用时不允许解绑。

| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 主键ID |
| scenario_id | INTEGER | NOT NULL | 场景方案ID |
| capability_id | INTEGER | NOT NULL | 能力ID |
| status | INTEGER | DEFAULT 1 | 状态：0-禁用 1-启用 |

**索引**：
- `uk_scenario_cap`：scenario_id + capability_id 联合唯一索引
- `idx_scenario_id`：scenario_id 普通索引

**业务约束**：
- 新增场景能力前必须校验 `product_capability` 中存在同产品、同能力的关联。
- 删除产品能力关联前必须确认该产品下没有任何场景继续引用该能力。

---

#### Terminal (终端版本表)
存储产品终端版本配置

| 字段名 | 类型 | 约束 | 说明 |
|-------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 主键ID |
| product_id | INTEGER | NOT NULL | 产品ID |
| name | TEXT | NOT NULL | 终端名称 |
| type | INTEGER | NOT NULL | 终端类型：1-APP 2-小程序 3-PC |
| version | TEXT | - | 版本号 |
| login_config | TEXT | - | 登录配置（JSON） |
| brand_config | TEXT | - | 品牌配置（JSON） |
| scenario_id | INTEGER | - | 关联场景方案ID |
| created_at | TEXT | DEFAULT datetime('now') | 创建时间 |

**索引**：
- `idx_product_id`：product_id 普通索引
- `idx_scenario_id`：scenario_id 普通索引

## 三、完整建表SQL

```sql
-- =============================================
-- 用户与认证模块
-- =============================================

-- 用户表
CREATE TABLE `user` (
  `id` INTEGER PRIMARY KEY AUTOINCREMENT,
  `username` TEXT NOT NULL UNIQUE,
  `password` TEXT,
  `phone` TEXT UNIQUE,
  `email` TEXT UNIQUE,
  `real_name` TEXT,
  `status` INTEGER DEFAULT 1,
  `created_at` TEXT DEFAULT (datetime('now')),
  `updated_at` TEXT DEFAULT (datetime('now'))
);

-- 企业认证表
CREATE TABLE `enterprise_auth` (
  `id` INTEGER PRIMARY KEY AUTOINCREMENT,
  `user_id` INTEGER NOT NULL,
  `enterprise_name` TEXT NOT NULL,
  `credit_code` TEXT,
  `license_url` TEXT,
  `legal_person` TEXT,
  `status` INTEGER DEFAULT 0,
  `created_at` TEXT DEFAULT (datetime('now'))
);

CREATE INDEX `idx_enterprise_auth_user_id` ON `enterprise_auth`(`user_id`);

-- =============================================
-- 团队管理模块
-- =============================================

-- 团队表
CREATE TABLE `team` (
  `id` INTEGER PRIMARY KEY AUTOINCREMENT,
  `name` TEXT NOT NULL,
  `owner_id` INTEGER NOT NULL,
  `description` TEXT,
  `created_at` TEXT DEFAULT (datetime('now'))
);

-- 团队成员表
CREATE TABLE `team_member` (
  `id` INTEGER PRIMARY KEY AUTOINCREMENT,
  `team_id` INTEGER NOT NULL,
  `user_id` INTEGER NOT NULL,
  `role` INTEGER DEFAULT 2,
  `status` INTEGER DEFAULT 1,
  `joined_at` TEXT,
  UNIQUE(`team_id`, `user_id`)
);

CREATE INDEX `idx_team_member_team_id` ON `team_member`(`team_id`);
CREATE INDEX `idx_team_member_user_id` ON `team_member`(`user_id`);

-- =============================================
-- 能力管理模块
-- =============================================

-- 能力表
CREATE TABLE `capability` (
  `id` INTEGER PRIMARY KEY AUTOINCREMENT,
  `code` TEXT NOT NULL UNIQUE,
  `name` TEXT NOT NULL,
  `description` TEXT,
  `icon_url` TEXT,
  `team_id` INTEGER,
  `epass_func_id` TEXT,
  `status` INTEGER DEFAULT 0,
  `created_at` TEXT DEFAULT (datetime('now'))
);

CREATE INDEX `idx_capability_team_id` ON `capability`(`team_id`);

-- 配置包表
CREATE TABLE `config_package` (
  `id` INTEGER PRIMARY KEY AUTOINCREMENT,
  `capability_id` INTEGER NOT NULL,
  `name` TEXT NOT NULL,
  `description` TEXT,
  `created_at` TEXT DEFAULT (datetime('now'))
);

CREATE INDEX `idx_config_package_capability_id` ON `config_package`(`capability_id`);

-- 配置包参数表
CREATE TABLE `config_package_item` (
  `id` INTEGER PRIMARY KEY AUTOINCREMENT,
  `package_id` INTEGER NOT NULL,
  `param_key` TEXT NOT NULL,
  `param_name` TEXT,
  `param_type` INTEGER NOT NULL,
  `param_value` TEXT,
  `sort_order` INTEGER DEFAULT 0
);

CREATE INDEX `idx_config_package_item_package_id` ON `config_package_item`(`package_id`);

-- =============================================
-- 产品管理模块
-- =============================================

-- 产品表
CREATE TABLE `product` (
  `id` INTEGER PRIMARY KEY AUTOINCREMENT,
  `code` TEXT NOT NULL UNIQUE,
  `name` TEXT NOT NULL,
  `description` TEXT,
  `icon_url` TEXT,
  `category` TEXT,
  `team_id` INTEGER NOT NULL,
  `status` INTEGER DEFAULT 0,
  `created_at` TEXT DEFAULT (datetime('now')),
  `updated_at` TEXT DEFAULT (datetime('now'))
);

CREATE INDEX `idx_product_team_id` ON `product`(`team_id`);

-- 产品能力关联表
CREATE TABLE `product_capability` (
  `id` INTEGER PRIMARY KEY AUTOINCREMENT,
  `product_id` INTEGER NOT NULL,
  `capability_id` INTEGER NOT NULL,
  `config_package_id` INTEGER,
  `status` INTEGER DEFAULT 1,
  UNIQUE(`product_id`, `capability_id`)
);

CREATE INDEX `idx_product_capability_product_id` ON `product_capability`(`product_id`);
CREATE INDEX `idx_product_capability_capability_id` ON `product_capability`(`capability_id`);

-- 管理后台菜单表
CREATE TABLE `admin_menu` (
  `id` INTEGER PRIMARY KEY AUTOINCREMENT,
  `product_id` INTEGER NOT NULL,
  `parent_id` INTEGER DEFAULT 0,
  `name` TEXT NOT NULL,
  `icon` TEXT,
  `path` TEXT,
  `sort_order` INTEGER DEFAULT 0,
  `visible_roles` TEXT
);

CREATE INDEX `idx_admin_menu_product_id` ON `admin_menu`(`product_id`);
CREATE INDEX `idx_admin_menu_parent_id` ON `admin_menu`(`parent_id`);

-- 场景方案表
CREATE TABLE `scenario` (
  `id` INTEGER PRIMARY KEY AUTOINCREMENT,
  `product_id` INTEGER NOT NULL,
  `code` TEXT NOT NULL,
  `name` TEXT NOT NULL,
  `login_identity_config` TEXT,
  `h5_portal_config` TEXT,
  `pc_portal_config` TEXT,
  `created_at` TEXT DEFAULT (datetime('now'))
);

CREATE INDEX `idx_scenario_product_id` ON `scenario`(`product_id`);

-- 场景能力配置表
-- 业务约束：capability_id 必须来自场景所属产品的 product_capability 关联；被场景引用时产品能力不可解绑。
CREATE TABLE `scenario_capability` (
  `id` INTEGER PRIMARY KEY AUTOINCREMENT,
  `scenario_id` INTEGER NOT NULL,
  `capability_id` INTEGER NOT NULL,
  `status` INTEGER DEFAULT 1,
  UNIQUE(`scenario_id`, `capability_id`)
);

CREATE INDEX `idx_scenario_capability_scenario_id` ON `scenario_capability`(`scenario_id`);

-- 终端版本表
CREATE TABLE `terminal` (
  `id` INTEGER PRIMARY KEY AUTOINCREMENT,
  `product_id` INTEGER NOT NULL,
  `name` TEXT NOT NULL,
  `type` INTEGER NOT NULL,
  `version` TEXT,
  `login_config` TEXT,
  `brand_config` TEXT,
  `scenario_id` INTEGER,
  `created_at` TEXT DEFAULT (datetime('now'))
);

CREATE INDEX `idx_terminal_product_id` ON `terminal`(`product_id`);
CREATE INDEX `idx_terminal_scenario_id` ON `terminal`(`scenario_id`);
```

## 四、JSON配置字段说明

### 4.1 login_identity_config (登录身份条件配置)

```json
{
  "version": 1,
  "identityTypes": ["recruiter", "teacher"]
}
```

`login_identity_config` 用于配置允许登录当前场景方案的账号身份白名单。当前统一身份字典为：`recruiter`（招聘者）、`candidate`（应聘者）、`student`（学员）、`level1_admin`（一级管理员）、`level2_admin`（二级管理员）、`super_admin`（超级管理员）、`teacher`（老师）、`parent`（家长）。

### 4.2 h5_portal_config / pc_portal_config (门户配置)

```json
{
  "external_config_url": "https://config.example.com/portal/h5",
  "theme": "default",
  "layout": "single"
}
```

### 4.3 login_config (登录配置)

```json
{
  "login_methods": ["password", "sms_code"],
  "password_policy": {
    "min_length": 8,
    "require_uppercase": true,
    "require_number": true
  },
  "security": {
    "max_fail_attempts": 5,
    "lock_duration": 30
  },
  "page_config": {
    "background_image": "/uploads/bg.jpg",
    "logo_position": "center"
  }
}
```

### 4.4 brand_config (品牌配置)

```json
{
  "app_name": "领航嘉",
  "logo": {
    "small": "/uploads/logo-small.png",
    "medium": "/uploads/logo-medium.png",
    "large": "/uploads/logo-large.png"
  },
  "theme": {
    "primary_color": "#1890ff",

  },
  "splash_screen": {

    "logo": "/uploads/splash-logo.png",
    "animation": "fade"
  },
  "copyright": "© 2026 领航嘉教育科技"
}
```

## 六、数据库版本管理

使用 TypeORM 的 Migration 功能管理数据库版本：

```typescript
// 创建迁移
npm run migration:create -- -n InitialSchema

// 执行迁移
npm run migration:run

// 回滚迁移
npm run migration:revert
```
